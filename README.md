# NPP-Lima

Modelado probabilistico de actividad sismica en Lima
mediante Neural Point Processes y redes LSTM.

## Objetivo
Evaluar modelos neuronales de procesos puntuales
para representar la ocurrencia temporal y la
magnitud de eventos sismicos del catalogo IGP.

## Metodologia
1. Analisis exploratorio de datos
2. Preparacion de secuencias
3. Construccion de la arquitectura NPP-LSTM
4. Entrenamiento y ablaciones
5. Evaluacion frente a Poisson y ETAS
6. Demostracion interactiva

## Estado
Proyecto en construccion.
